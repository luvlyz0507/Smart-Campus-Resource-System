Smart Campus Resource Management System

Project Description

The Smart Campus Resource Management System is a C++ program that manages student records and analyzes campus resource utilization.

 Features

* Display all students
* Search student by ID
* Add new student
* Update student information
* Delete student records
* Display resource matrix
* Analyze resource utilization
* Generate a report
* Input validation

Data Structures Used

* Structure (`struct`) for student records
* Array for storing student records
* Two-dimensional array for the resource matrix
* List for resource IDs

 Matrix Processing

The system uses a 4×4 matrix to represent campus resource utilization.

The program calculates the total utilization for each department and the overall resource utilization.

Testing

The project includes at least 10 test cases covering:

* Normal input
* Invalid input
* Duplicate student ID
* Student search
* Student update
* Student deletion
* Maximum capacity
* Matrix processing

Test cases and screenshots are available in the documentation and screenshots folders.
